# akshaysh27.github.io

Akshay Sharma — AI Solutions & Forward Deployment. Personal profile site, hosted on GitHub Pages.

## Publish steps

1. On GitHub, create a public repository named exactly `akshaysh27.github.io`.
2. Upload `index.html` to the repository root.
3. Settings → Pages → Source: Deploy from a branch, branch `main`, folder `/ (root)`.
4. The site goes live at https://akshaysh27.github.io within a few minutes.

## Files

- `index.html` — the whole site (single page, no build step, no photo).
- `../profile-draft.md` — the finalised profile content this page was built from.

## Editing

Edit `index.html` directly; push to `main` and Pages redeploys automatically.
